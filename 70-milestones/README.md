# Milestones (`70-milestones`)

## Purpose

Milestones record implementation evidence for each planning milestone. These
are completion logs, not conceptual work. Each note documents what a phase
produced (spec chapters, test IDs, design decisions) and links back to the
phase plan and the resulting specification chapter.

## What belongs here

Put durable implementation records here. Each note documents:
- Which section of which phase was implemented
- Which specification chapter was produced
- What test IDs were defined
- Design decisions and constraints applied
- Open questions or deferred work

Do not put ideas, syntheses, or research findings here — those belong in
`20-notes/`. Do not put planning documents here — those belong in
`.spec/planning/agentic-system/`.
